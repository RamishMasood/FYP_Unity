# 📘 Augmented Reality Based Learning of Computer Fundamentals

## 📖 Introduction
In today’s world, students learn through many traditional methods such as classroom lectures, books, notes, and digital devices. However, these methods often fail to help students properly understand topics that require visual clarity, especially computer hardware components.

As technology continues to grow, education must also adopt modern tools to improve the learning experience.

## 🚀 Project Overview
This project uses **Augmented Reality (AR)** to make learning more interactive, visual, and effective. AR changes when and where students learn by bringing digital 3D objects into the real world through a mobile device.

Our project focuses on the **Computer Fundamentals** course. We created **3D models of computer hardware components** (such as motherboard, NIC, hard drive, etc.) and integrated them into an AR-based learning app using Unity and Vuforia.

## 🎯 Why AR for Learning?
Traditional learning has limitations like:
- Students find it difficult to visualize hardware through 2D images  
- Engagement is low  
- Limited hands-on experience for beginners  

AR solves these challenges by:
- Displaying hardware components in **3D with full rotation**
- Making learning fun and interactive
- Helping students understand concepts faster and more clearly

## 🎯 Goal
Our goal is to reshape the learning experience through AR by making computer fundamentals:
- More interactive  
- More effective  
- Easier to understand  
- Enjoyable for students
